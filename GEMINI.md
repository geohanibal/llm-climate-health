# Context for Gemini

This repository is the practical part of Sergi Koniashvili's bachelor thesis
(Informatics, University of Bremen): an LLM-driven ETL platform for
climate-health data integration. See `README.md` for the system.

**Before any thesis-related task (literature, motivation, requirements, case
studies, writing), read `docs/thesis/THESIS_KNOWLEDGE_BASE.md` and follow its
rules in §0.** In particular: never invent sources or quotes, never reuse the
false claims listed in §6, and do not overclaim system capabilities (§5).

When you learn a new verified fact or a decision is made, propose an update to
that file (do not silently change VERIFIED entries).

**Before and after any code change, read `docs/thesis/CHANGE_DOCUMENTATION_GUIDE.md`**:
a code task is only done when tests AND the listed documents (requirements
catalogue DE/EN/KA, `docs_ka/dokumentacia.tex`, READMEs, TESTING_GUIDE,
knowledge base proposal) are updated. Code tasks: `docs_ka/motivacia/gemini_tasks_02.md`
(B, C, D) and `docs_ka/motivacia/gemini_tasks_03.md` (E, F).

Do not commit to git unless explicitly asked.
